The Catacombs of Lirgard

아트 교체 가이드

「리르가드의 미궁」에 쓰이는 그림 파일의 위치와 규칙을 정리한 문서다. 그림 파일만 같은 이름으로 바꾸면 게임 코드를 고치지 않아도 새 그림이 나온다.

1. 폴더 구조

lirgard/
├─ index.html            게임 본체
└─ assets/
   ├─ manifest.json      그림 목록 (파일 경로 · 프레임 수 · 속도)
   ├─ CREDITS.txt        그림 출처와 라이선스
   ├─ party/             파티 초상 (직업별)

3. 그림 규칙

애니메이션은 가로 한 줄 스트립

움직이는 그림은 프레임을 왼쪽에서 오른쪽으로 한 줄에 이어 붙인 PNG 한 장이다. 모든 프레임은 같은 크기여야 한다. 게임은 「이미지 너비 ÷ frames」로 한 프레임 너비를 계산한다.

[프레임1][프레임2][프레임3][프레임4]   ← 16×28 짜리 4장이면 이미지는 64×28
  • 배경은 투명(PNG 알파)으로 둔다. 미궁 돌벽 위에 그대로 겹쳐 그린다.
  • 몬스터는 정면을 보게, 발이 그림 맨 아래에 닿게 그린다. 게임이 바닥선에 맞춰 세운다.
  • 정지 그림도 된다. 그때는 manifest의 frames를 1로 둔다.

도트 그림과 일반 일러스트

  • 도트 그림은 원본 크기(16~48px)로 넣고 "pixel": true. 게임이 정수 배로 확대해서 선명하게 보인다.
  • 고해상도 일러스트(손그림, 3D 렌더 등)는 "pixel": false. 높이 256~512px 정도를 권한다. 화면 크기에 맞춰 부드럽게 줄인다.

화면에 나오는 높이

그림 크기와 상관없이 게임이 높이를 맞춘다. 보통 몬스터 약 96px, 큰 몬스터(오우거) 약 120px, 보스 약 170px, 파티 초상 40px이다. 몬스터가 4마리 이상이면 조금 작아진다.

4. manifest.json

그림마다 한 줄씩 적혀 있다. 파일 이름이나 프레임 수를 바꿀 때만 고치면 된다.

{
  "party": {
    "전사": { "src": "party/warrior.png", "frames": 4, "fps": 6, "pixel": true }
  },
  "monsters": {
    "goblin": { "src": "monsters/goblin.png", "frames": 4, "fps": 6, "pixel": true },
    "boss":   { "src": "monsters/boss.png",   "frames": 3, "fps": 5, "pixel": true }
  },
  "props": {
    "chest":  { "src": "props/chest.png",     "frames": 1, "fps": 1, "pixel": true }
  }
}
항목뜻
srcassets 폴더 기준 파일 경로
frames스트립에 든 프레임 수 (정지 그림은 1)
fps1초에 넘기는 프레임 수. 4~8이 자연스럽다
pixel도트 그림이면 true, 일반 일러스트면 false

왼쪽의 이름("전사", "goblin" 등)은 게임 코드가 찾는 열쇠라서 바꾸면 안 된다. 바꾸는 것은 오른쪽 값뿐이다.

5. 그림 바꾸는 순서

  1. 새 그림을 위 규칙대로 만든다 (투명 배경 PNG, 가로 스트립).
  2. 바꿀 파일과 같은 이름으로 저장한다. 예: 고블린을 바꾸려면 goblin.png.
  3. 프레임 수가 원래와 다르면 manifest.json의 frames를 고친다. 도트가 아니면 pixel을 false로.
  4. 게임에 반영한다.
    • Claude에게 맡길 때: 대화에 그림 파일을 올리고 "이 그림을 monsters/goblin.png로 바꿔줘, 4프레임이야"처럼 말한다. 교체 후 같은 게임 링크에 다시 올린다.
    • 직접 할 때: 게임 폴더를 GitHub 저장소로 옮겨 두면 파일만 바꿔 커밋하고, Claude에게 그 저장소로 다시 게시해 달라고 하면 된다.

그림 파일을 못 찾거나 깨졌으면 게임이 멈추지 않고 내장 아이콘(실루엣)으로 대신 그린다. 그러니 그림이 아이콘으로 나오면 파일 이름이나 manifest 경로부터 확인하면 된다.

6. 그림이 아닌 것

  • 이펙트(베기 궤적, 불꽃, 신의 빛, 잠의 안개, 약화, 저주의 화살, 피해 숫자, 화면 흔들림)는 코드로 그린다. 그림 파일이 없다.
  • 미궁의 돌벽·바닥·촛불빛도 코드로 그린다.
  • 마을 간판, 계단 표시, 아이콘은 game-icons.net 아이콘을 게임 안에 넣어 두었다.
  • 새 몬스터나 새 직업을 추가하려면 그림뿐 아니라 능력치 등 코드도 필요하다. Claude에게 "monsters/에 bat.png를 넣고 1층에 박쥐를 추가해줘"처럼 요청하면 된다.

7. 다른 무료 그림을 찾을 때

상업적으로도 쓸 수 있는 라이선스(CC0, CC BY)인지 꼭 확인한다. 평판이 좋은 곳은 다음과 같다.

  • 0x72 DungeonTileset II (itch.io) — 지금 쓰는 그림. CC0. 같은 작가의 확장판도 있다.
  • OpenGameArt.org — 도트·일러스트 다수. 그림마다 라이선스가 다르니 하나씩 확인.
  • Kenney.nl — 전부 CC0. 깔끔하지만 고딕풍은 적다.
  • itch.io 무료 에셋 — "dark fantasy", "gothic", "pixel monster"로 검색. 게시글마다 이용 조건이 다르다.

CC BY 그림은 작가 이름을 게임 화면(하단 출처)에 적어야 한다. 바꾼 그림의 출처는 assets/CREDITS.txt에도 함께 적어 두자.
